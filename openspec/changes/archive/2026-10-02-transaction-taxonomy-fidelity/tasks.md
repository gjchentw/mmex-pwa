- F1 — The `namesEqual` test first expected `Époque` and `ÉPOQUE` to differ; they differ only in ASCII letters, which NOCASE folds, so they are equal. The expectation was wrong and was corrected before the box was checked; the spec scenario (`Époque` vs `époque`) was unaffected.
- F2 — The payee purge test first took the purged transaction's own `ATTACHMENT_V1` delete (bound `['Transaction', 9]`) for the payee's; the code was right (the ledger hard delete precedes the payee cascade) and the assertion now checks both deletes in order.
- F3 — Three new assertions passed on the old code (child under a hidden parent is `ACTIVE 1`; move to `-1`; the unused-tag deletion shape). They are kept as regression guards and are not counted as reds.
- F4 — Design revised during implementation and recorded in design.md 1.1.0: D2 (`state` is a field), D4 (`hardDeleteStatements` already existed), D5 (the predicate is the ledger's `COALESCE(DELETEDTIME, '') = ''`), D8 (series split link cleanup by subquery, not a pre-read, so the synchronous builders stay synchronous). None changes a spec.
- F5 — `tagRepo.relocate` briefly carried a `0 AS transactions` column in its link-count query so the test fake would answer it; removed before the box was checked, and the fake now answers `AS links` on its own.
